## Fly Sword（御剑飞行）

> 每个人都有一个仙剑梦……

一个 Minecraft Forge 模组，为**剑**添加「御剑飞行」「剑气」「剑意通明」三个附魔，以及一套由境界解锁的剑招。

附魔都能通过正常生存途径获取，等级上限 5 级；御剑飞行时剑身后会拖出随等级变化的粒子尾迹。

### 环境要求

| 项目 | 版本 |
| --- | --- |
| Minecraft | 1.20.1 |
| Forge | 47.x |
| Java | 17 |
| 模组版本 | 1.2.0 |

客户端与服务端都需要安装。

### 附魔

#### 御剑飞行

| 项目 | 值 |
| --- | --- |
| 注册名 | `flysword:flysword` |
| 稀有度 | 常见（COMMON） |
| 可附魔物品 | 剑 |
| 最大等级 | 5 |

手持附魔剑**右键**即可召唤飞剑并自动骑乘，召唤时剑消耗 1 点耐久。

飞行性能随附魔等级提升，1 级与旧版手感一致：

| 等级 | 水平速度倍率 | 升降加速度 |
| --- | --- | --- |
| I | 2.0 | 0.03 |
| II | 2.4 | 0.04 |
| III | 2.8 | 0.05 |
| IV | 3.2 | 0.06 |
| V | 3.6 | 0.07 |

飞行时剑身后会拖出粒子尾迹，**风格随境界递进**，粒子数量也随之增加（I 级每刻 1 个，V 级每刻 5 个）：

| 等级 | 境界 | 拖尾风格 |
| --- | --- | --- |
| I | 炼气 | 灵气符文（青绿咒文） |
| II | 筑基 | 剑罡电芒（青白电光） |
| III | 金丹 | 真元灵光（纯白光点） |
| IV | 元婴 | 幽蓝灵焰 |
| V | 化神 | 金霞仙光（金色仙尘与金光交替） |

悬停不动时不会产生尾迹。

飞行操作（按键可在「选项 → 控制」中重新绑定，条目名 **飞剑下降**）：

| 操作 | 默认按键 |
| --- | --- |
| 上升 | 空格 |
| 下降 | 左 Ctrl |
| 前后左右 | W / A / S / D |
| 收剑下马 | 左 Shift |

收剑后剑会回到背包，背包已满则掉落在脚下。飞剑实体无敌，不会受伤或掉落。

> 左 Ctrl 同时是原版的「疾跑」键，飞行时会一并触发疾跑，不影响飞行速度。

#### 剑气

| 项目 | 值 |
| --- | --- |
| 注册名 | `flysword:swordbeam` |
| 稀有度 | 常见（COMMON） |
| 可附魔物品 | 剑 |
| 最大等级 | 5 |

手持附魔剑**左键点击空气**发射剑气。

- 伤害 = `(玩家攻击力 + 武器附魔伤害加成) × (等级 × 0.25)`
- 每命中一个目标后，后续伤害 × 0.8
- 冷却 = `80 − 等级 × 13` 刻
- 飞行速度 = `1.0 + 等级 × 0.15`
- 存在时间 = `12 + 等级` 刻
- 满级（5 级）可穿透多个目标，未满级命中即消失
- 每次释放有 50% 概率消耗 1 点耐久

#### 剑意通明

| 项目 | 值 |
| --- | --- |
| 注册名 | `flysword:swordintent` |
| 稀有度 | 常见（COMMON） |
| 可附魔物品 | 剑 |
| 最大等级 | 5 |

持剑时提升攻击伤害，等级曲线与原版**锋利**一致：1 级 +1.0、5 级 +3.0（公式 `1.0 + (等级 − 1) × 0.5`）。

与锋利**不互斥**，两者可以叠加。

### 剑罡护体与剑招

#### 剑罡护体（被动）

手持带有**御剑飞行**附魔的剑受击时，按境界减免伤害，无需按键：

| 等级 | 减伤 |
| --- | --- |
| I | 10% |
| II | 15% |
| III | 20% |
| IV | 25% |
| V | 30% |

减伤有上限（默认 80%），防止配置叠加后完全免伤。触发时身上会缠出一道随境界变化的灵气螺旋并播放挡格音效，粒子风格与飞行拖尾的五档境界一致。

#### 招式键与释放方式

剑招统一由两个专用招式键释放，**招式是否可用由手持剑上御剑飞行的境界等级（1 ~ 5）决定**，不需要为每个招式单独附魔。按键可在「选项 → 控制」中重新绑定。

| 招式 | 默认按键 | 境界门槛 | 冷却（5 级） |
| --- | --- | --- | --- |
| 剑气纵横 | `V` | 1 级 | 25 刻 |
| 御剑术 | `V` + 潜行 | 3 级 | 25 刻 |
| 万剑归宗 | `B` | 4 级 | 80 刻 |
| 剑雨 | `B` + 潜行 | 5 级 | 110 刻 |

冷却按「玩家 + 招式」**分别计时**，四个招式互不阻塞；冷却中或境界不足时会在动作栏提示原因。

万剑归宗与剑雨还带自动索敌：半径（默认 16 格）内有敌对生物时自动瞄准最近的一只，没有则按准星方向释放。

#### 剑气纵横

一次放出多道扇形剑气，道数等于境界等级（1 级 1 道、5 级 5 道，相邻偏转 8 度）。

- 单道伤害 = `(玩家攻击力 + 武器附魔伤害加成) × (境界 × 0.25)`
- 多道时单道伤害 × 0.6，避免总输出随道数线性叠加
- 冷却 = `100 − 境界 × 15` 刻

#### 御剑术

剑离手飞出，自主追杀附近敌对生物，命中达到上限或超时后飞回主人并归还背包。

- 命中伤害 = `(玩家攻击力 + 武器附魔伤害加成) × (境界 × 0.4)`
- 搜索半径 16 格，每 5 刻重新搜索一次目标
- 最多命中 5 次，两次命中间隔 10 刻
- 最长存活 200 刻；离主人超过 24 格立即返航
- 返航超过 80 刻仍未到家则强制召回，避免绕圈或卡住时丢剑

#### 万剑归宗

身后按环形升起多柄剑，悬停蓄势后**整束剑沿同一方向平行齐射**，命中达到上限或超时后消散。

- 剑数 = `3 + (境界 − 1) × 1`，单次最多 8 柄
- 命中伤害 = `(玩家攻击力 + 武器附魔伤害加成) × (境界 × 0.35)`
- 蓄势 16 刻，升起与齐射速度 1.1 格/刻
- 单柄最多命中 3 次，齐射后最长存活 60 刻
- 冷却 = `180 − 境界 × 20` 刻

#### 剑雨

以准星落点为中心，在半径内分批天降落剑，落点先用粒子提示范围。

- 剑数 = `6 + (境界 − 1) × 3`，单次最多 20 柄，分 3 波、每波间隔 6 刻
- 单道伤害 = `(玩家攻击力 + 武器附魔伤害加成) × (境界 × 0.3)`
- 落点半径 5 格；半径内有敌对生物时改为直接朝它们落剑，没有才随机散布
- 落剑在落点上空 8 格生成，以 1.6 格/刻垂直下坠
- 冷却 = `260 − 境界 × 30` 刻

> 以上数值均为默认值，全部可在[配置文件](#配置)中调整。招式的伤害、冷却与实体数上限都在服务端计算。

### 生存模式获取

三个附魔都可通过正常生存途径获得，等级曲线一致：

| 途径 | 可获得等级 | 说明 |
| --- | --- | --- |
| 附魔台 | 1 ~ 4 级 | 0 书架出 1 级；15 书架时三个槽位分别可出 1~2 / 1~3 / 4 级 |
| 附魔台（书） | 1 ~ 4 级 | 可刷出附魔书，用于铁砧合成与交易 |
| 铁砧合成 | 5 级 | 两本 4 级书合成 1 次即可满级 |
| 村民图书管理员 | 1 ~ 5 级 | 与原版一致，等级随机 |
| 战利品箱 | 1 ~ 5 级 | 非宝藏附魔，可随机出现在结构战利品中 |

附魔台的成本区间按等级均分为 8 格：`L1 [1,8]`、`L2 [9,16]`、`L3 [17,24]`、`L4 [25,32]`、`L5 [33,40]`。区间首尾相接且互不重叠，成本唯一映射到等级、无空档。

15 书架时附魔台顶槽成本恒为 30，正好落在 4 级区间，因此**附魔台最高出 4 级**；5 级区间 `[33,40]` 超出附魔台上限，需靠铁砧合成。

三个附魔可同时附在同一把剑上，也能与锋利、节肢杀手等原版武器附魔共存。

### 安装

1. 安装 Minecraft 1.20.1 与对应版本的 Forge（47.x）
2. 将 `flysword-1.2.0.jar` 放入 `.minecraft/mods`
3. 启动游戏

也可以直接用指令附魔：

```
/give @s diamond_sword{Enchantments:[{id:"flysword:flysword",lvl:5},{id:"flysword:swordbeam",lvl:5},{id:"flysword:swordintent",lvl:5}]}
```

### 配置

服务端与客户端都会生成 `config/flysword-common.toml`，可脱离源码调整平衡参数。

| 分节 | 内容 |
| --- | --- |
| `[fly_sword]` | 水平速度倍率、升降垂直加速度、水平/垂直阻尼 |
| `[fly_trail]` | 飞行拖尾粒子的开关与密度（风格由附魔等级决定，不可配置） |
| `[sword_beam]` | 冷却、伤害系数、飞行速度、存活时间、穿透衰减、击退强度、耐久消耗概率 |
| `[sword_ward]` | 剑罡护体的开关、音效开关、减伤比例与上限 |
| `[sword_intent]` | 剑意通明的额外攻击伤害 |
| `[sword_skill]` | 招式共用参数（准星射程、自动索敌半径）与剑气纵横、御剑术的冷却 |
| `[flying_sword]` | 御剑术的解锁等级、搜索半径与频率、命中上限、存活时间、飞行速度、转向与返航参数 |
| `[myriad_swords]` | 万剑归宗的解锁等级、剑数、实体数上限、升起编队与齐射参数、冷却 |
| `[sword_rain]` | 剑雨的解锁等级、落点半径、剑数、实体数上限、分波参数、落剑速度、冷却 |

带 `Base` / `PerLevel` 后缀的项按 `实际值 = base + (附魔等级 - 1) × perLevel` 计算（冷却项按 `基数 − 境界等级 × 每级减少` 计算）。

注意：飞剑的移动由骑乘者客户端模拟，`[fly_sword]` 与 `[fly_trail]` 按各客户端本地配置生效；`[sword_beam]`、`[sword_ward]`、`[sword_intent]` 与全部分招式参数在服务端计算，以服务端配置为准。

### 从源码构建

```bash
./gradlew build
```

产物位于 `build/libs/flysword-1.2.0.jar`。

开发环境运行：

```bash
./gradlew runClient   # 启动客户端
./gradlew runServer   # 启动专用服务端
```

### 项目结构

```
src/main/java/com/flysword/
├── FlySwordMod.java        模组入口与右键/左键/受击事件处理
├── config/                 平衡参数配置（ForgeConfigSpec）
├── enchantment/            附魔定义与注册（御剑飞行、剑气、剑意通明）
├── entity/                 飞剑载具、御剑术飞剑、剑气投射物
├── key/                    按键绑定与招式键输入
├── loader/                 实体类型注册、客户端渲染器注册
├── network/                网络包（剑气发射、招式释放）
├── render/                 实体渲染器
└── utils/                  网络通道、剑气发射器与工具类

src/main/resources/
├── META-INF/mods.toml      模组元数据
├── pack.mcmeta
└── assets/flysword/        语言文件与贴图
```
